## 💡 Consejos para el Éxito

### Antes de Programar
1. **Lee el enunciado completo** 2-3 veces
2. **Identifica los datos de entrada** y salida esperada
3. **Planifica tu algoritmo** en papel o pseudocódigo
4. **Divide el problema** en pasos pequeños

### Durante la Programación
1. **Empieza simple:** Primero haz que funcione, luego optimiza
2. **Prueba frecuentemente:** Compila y ejecuta después de cada paso
3. **Usa nombres descriptivos:** `totalVentas` en vez de `x`
4. **Comenta tu código:** Explica el "por qué", no el "qué"

### Si te Atoras
1. **Consulta la guía teórica** para refrescar conceptos
2. **Revisa los ejemplos** de la guía
3. **Lee el código de solución** línea por línea
4. **Modifica el ejemplo** hasta que lo entiendas
5. **Intenta de nuevo** desde cero

### Después de Resolver
1. **Compara tu solución** con la oficial
2. **Busca optimizaciones** posibles
3. **Añade validaciones** de entrada
4. **Crea variaciones** del ejercicio

## 🐛 Solución de Problemas Comunes

### Error: "cannot find symbol"
```
Problema: Variable o método no declarado
Solución: Verifica que hayas declarado todas las variables antes de usarlas
```

### Error: "ArrayIndexOutOfBoundsException"
```
Problema: Intentas acceder a un índice que no existe
Solución: Verifica que 0 <= índice < arr.length
```

### Error: "NullPointerException"
```
Problema: Intentas usar un objeto que es null
Solución: Inicializa las listas: new ArrayList<>()
```

### El promedio no es correcto
```
Problema: División entera (5/2 = 2 en vez de 2.5)
Solución: Usa (double) para convertir: (double) suma / cantidad
```

### Los números no se ordenan bien
```
Problema: Ordenamiento incompleto
Solución: Verifica los límites de tus ciclos en bubble sort
```
